# Todoist

Find, create, update and complete tasks and manage projects through [Todoist's official MCP server](https://github.com/Doist/todoist-mcp).

## Connect

1. Open **Settings → Plugins → Marketplace** in Alan.
2. Install **Todoist** for yourself or your team.
3. Connect your Todoist account and complete OAuth consent.

The plugin uses `https://ai.todoist.net/mcp`. No local server or API key is required for this OAuth connection. Tool availability follows the connected account's access.

If access is revoked, reconnect from Alan's Connections panel.
